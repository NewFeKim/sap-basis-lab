[7] ABAPReadSyslog (SM21) 출력 형식
---------------------------------------------------------------------
접근 경로 : SAP 실환경에서 아래 명령어 실행 후 출력 캡처 요청
  sapcontrol -nr 00 -function ABAPReadSyslog
확인 항목 :
  - 컬럼 목록 (Time, MsgNo, Type, TD, Group, Program, Host, Message 등)
  - 날짜/시간 형식
  - 메시지 타입 코드 (E=Error, W=Warning, I=Info 등)

[8] dpmon 실환경 출력 캡처 요청
---------------------------------------------------------------------
현재 구현한 dpmon 컬럼:
  No Ty Pid Status Start Err Sem CPU Time Program Cl User

실제 환경에서 아래 명령어 실행 후 출력 붙여넣기 요청:
  dpmon
  (또는 sm50 트랜잭션 화면 캡처)

확인 항목 :
  - 컬럼 순서가 현재 구현과 동일한지 여부
  - Reason, Action, Table 컬럼 실제 표시 여부
  - Status 값 종류 (Wait/Run/PRIV/Hold 등)
